# Sprint 2.4 — York Protocol Reference

Climate Bridge 1.0.0-alpha.6 introduces the permanent York TFIAC protocol evidence store under `protocols/york/`.

The reference includes evidence-handling rules, capture import guidance, a packet-record schema, an empty non-executable packet template, observed byte-change notes, state-mapping and checksum research worksheets, and regression tests preventing unverified frames from being treated as executable library entries.

No guessed native frame was added. Relay remains the active transport.
