# Historical engineering records

This directory preserves the alpha.20 engineering notes approved by the
Phase 1 reconciliation manifest.

These files describe earlier York Hybrid Bridge and Climate Bridge development
checkpoints. Their versions, test counts, release labels and qualification
instructions are historical evidence, not current operating or release
guidance.

For the current `1.0.0-alpha.20` baseline, use:

- `README.md`;
- `RELEASE_NOTES.md`;
- `ROADMAP.md`;
- `RELEASE_CHECKLIST.md`; and
- the current guides in `docs/`.
